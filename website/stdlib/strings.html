String methods

Stable — pure slice operations, no I/O, conformance-covered.

Called directly on any string value.

A string is a sequence of UTF-8 bytes: "é".length is 2, and s[i], charCodeAt, slice, indexOf and the rest count bytes. On the Node target (--target node) strings are bytes too — a program computes the same lengths, indexes and code units there as natively, and text is converted once, at the boundary, where it reaches a file, the console or a process.
