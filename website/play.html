Playground

Write Lumen and run it in your browser: the program is compiled to a single WebAssembly module and executed here. Packages import straight from a URL, and some (QuickJS, SQLite) embed real C libraries into the wasm. Pick an example or edit freely; Share copies a link to whatever is in the editor. Async isn’t available in the in-browser target yet.
