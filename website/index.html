Familiar syntax, fixed static types, no runtime, just a native executable.

interface Point {
  x: int;
  y: int;
}

function distanceSq(a: Point, b: Point): int {
  let dx = a.x - b.x;
  let dy = a.y - b.y;
  return dx * dx + dy * dy;
}

let origin: Point = { x: 0, y: 0 };
let p: Point = { x: 3, y: 4 };
console.log(`distance² = ${distanceSq(origin, p)}`);  // distance² = 25

What's in the language

A predictable static subset of TypeScript, no prototypes, no eval, no dynamic shapes.

Static types

Local inference, int/i64/number/bool/string, float & hex/binary literals. Numeric promotion (int + number) and lossless int → i64 widening, just like TypeScript's single number.

Records & interfaces

Closed object shapes, nested records, arrays of records, enums. Structural width subtyping: a wider record flows into a narrower one, so interface parameters accept any matching shape.

Full control flow

if/else if, while, do, C‑style for, for…of (arrays, strings, Set, Map), for…in, switch (exhaustive over literal unions), ternary, and labeled break/continue.

Null safety & narrowing

T | null, optional ? fields, ??, optional chaining ?./?.[i]/?.(). Flow narrowing across if/else, guard clauses (if (x == null) return), while, &&/||, and deep field paths (a.b.c != null) — plus discriminated-union complement narrowing.

First-class functions

Function types, arrow functions, and capturing closures.

Classes & inheritance

extends, super, public/private/protected, #private fields, static, readonly, and get/set.

Strings

Single‑ and double‑quoted literals, and template literals `hi ${name}` with string & numeric interpolation.

Regex

/pattern/ literals and .test(). Anchored patterns compile to specialized native matchers at build time, ~3× faster than V8 on checks like semver and identifiers. Everything else falls back to a built-in engine — every pattern works, not just the fast-path ones.

defer

Scope‑exit cleanup, last‑in‑first‑out.

Built-in tests

test "…" { expect(…); } run with lumen test.

C FFI

declare function + // @link call native C libraries, scalars and strings marshal across the boundary.

String methods

split, slice, trim, includes, indexOf, replace, repeat, padStart, toUpperCase, and more.

Array methods

map, filter, reduce, forEach, find, some, every, includes, indexOf, join.

Generics

Generic functions, classes, and interfaces with Array<T>, monomorphized at compile time, no boxing.

Type aliases & unions

type aliases, discriminated unions narrowed by a literal tag with exhaustive switch, string‑literal unions, as assertions, satisfies, and readonly arrays.

Built‑in helpers

Date.now(), Object.keys(record), Array.isArray/Array.from/Array.of, JSON.stringify/parse<T>, parseInt/parseFloat, and the full Math/Number surface.

Error handling

try/catch/finally and throw, propagating across functions, methods, and constructors; readable .message, optional catch binding, and full stack traces on uncaught errors.

Operators

Full arithmetic, bitwise, and shift set, with every compound-assignment form (+=, &&=, ??=, <<=, **=, and more).

Maps, Sets & tuples

Map<K, V> and Set<T> (both iterable with for…of), and fixed-shape tuple types like [int, string].

EventEmitter

Statically-typed EventEmitter<T>, one payload type per instance. ~3.5× faster than Node's native EventEmitter on a tight emit loop (10M emits, one listener).

async / await

async functions return Promise<T> and await resolves them on a fast native event loop. setTimeout/setInterval and their clear* counterparts included.

worker_threads

Worker.run(fn) spawns a real, detached OS thread and hands back a Promise<T> — genuine CPU parallelism, not a simulated one, since Lumen compiles to native code with no per‑thread interpreter overhead to pay.

Buffer

A real byte‑array type, distinct from string at compile time. Buffer.from/.alloc, utf8/hex/base64 encodings, .slice/.at/.equals. crypto.hmacSync and AES‑256‑GCM encryptSync/decryptSync both read and return it.

Networking & I/O

net TCP sockets, an http client & concurrent server, process.stdin/stdout/stderr as streams, readline.question for interactive input, and zlib gzip/deflate compression.

Flexible parameters

Default values, rest parameters, and spread, checked statically, no arguments object. Object shorthand { x } and computed keys.

Modules

Default, named, and import * as ns imports, and export … from re-exports, from a relative file or an https:// URL — a package is just a URL.

Native output

Compiles to a small, fast, dependency‑free native binary.

Closures that compile

Capture locals by value, lowered to a heap environment, no GC.

function makeAdder(n: int): (x: int) => int {
  return (x: int) => x + n;
}

let add10 = makeAdder(10);
console.log(add10(5));   // 15

let factor = 3;
let nums: int[] = [1, 2, 3];
for (const v of nums) {
  console.log((v: int) => v * factor);  // closes over `factor`
}

Classes

Fields, a constructor, this, and methods, instances are heap structs.

class Counter {
  count: int;
  constructor(start: int) {
    this.count = start;
  }
  increment(): void {
    this.count += 1;
  }
  get(): int {
    return this.count;
  }
}

let c = new Counter(5);
c.increment();
console.log(c.get());   // 6

Methods on strings and arrays

The familiar collection and string methods, statically typed and compiled.

let nums: int[] = [1, 2, 3, 4, 5];
let doubled = nums.map((n: int) => n * 2);
let evens = nums.filter((n: int) => n % 2 == 0);
let total = nums.reduce((acc: int, n: int) => acc + n, 0);

console.log(doubled.join(", "));   // 2, 4, 6, 8, 10
console.log(evens.join(", "));     // 2, 4
console.log(total);                // 15

let s = "  Hello, World  ";
console.log(s.trim().toUpperCase());   // HELLO, WORLD
console.log(s.trim().split(", ")[1]);  // World

Generics, monomorphized

Write once over a type parameter; each instantiation compiles to specialized code, no boxing.

function identity<T>(x: T): T {
  return x;
}

class Box<T> {
  value: T;
  constructor(v: T) {
    this.value = v;
  }
  get(): T {
    return this.value;
  }
}

console.log(identity<int>(42));      // 42
console.log(identity<string>("hi"));  // hi
let b = new Box<int>(7);
console.log(b.get());                 // 7

Maps, Sets, and tuples

Typed keyed collections and fixed-shape tuples, with the methods you expect.

let counts: Map<string, int> = new Map<string, int>();
counts.set("apples", 3);
counts.set("pears", 5);
console.log(counts.get("apples"));   // 3
console.log(counts.has("pears"));    // true

let tags: Set<string> = new Set<string>();
tags.add("red");
tags.add("red");
tags.add("blue");
console.log(tags.size);   // 2

let pair: [string, int] = ["age", 30];
console.log(pair[0]);   // age
console.log(pair[1]);   // 30

Type narrowing that just works

Discriminated unions, guard clauses, and deep null checks all narrow the way you expect — statically, with no casts.

type Ok = { kind: "ok", value: int };
type Err = { kind: "err", message: string };
type Result = Ok | Err;

function describe(r: Result): string {
  if (r.kind === "err") {
    return "failed: " + r.message;   // r is Err here
  }
  return "value " + String(r.value); // r is Ok here
}

function firstWord(s: string | null): string {
  if (s == null) return "(none)";    // guard: s is string below
  return s.split(" ")[0];
}

console.log(describe({ kind: "ok", value: 42 }));   // value 42
console.log(firstWord("hello world"));              // hello

async / await

Async functions return a Promise<T>; await resolves it on a fast native event loop.

async function fetchValue(n: int): Promise<int> {
  return n * 2;
}

async function total(): Promise<int> {
  let a: int = await fetchValue(10);
  let b: int = await fetchValue(11);
  return a + b;
}

console.log(await total());   // 42

Errors with try / catch / finally

Exceptions propagate across calls — through functions, methods, and constructors — and finally runs on every path. All compiled to native code, no unwinder runtime.

function parsePort(s: string): int {
  const n: int = parseInt(s) ?? 0;
  if (n < 1 || n > 65535) {
    throw new Error("bad port: " + s);
  }
  return n;
}

function connect(s: string): void {
  console.log("connecting to " + String(parsePort(s)));  // may throw
}

try {
  connect("8080");     // connecting to 8080
  connect("99999");
} catch (e) {
  console.log("error: " + e.message);   // error: bad port: 99999
} finally {
  console.log("done");
}

Call native libraries

Write a declare function and link a C library, no bindings generator, no runtime. (extern function works too.)

// @link m
declare function pow(base: number, exp: number): number;
declare function sqrt(x: number): number;

let hypotSq = pow(3.0, 2.0) + pow(4.0, 2.0);
console.log(sqrt(hypotSq));   // 5
console.log(pow(2.0, 10.0));  // 1024

C++ through an extern "C" shim

Lumen links the C ABI, so expose the C++ you need behind extern "C", then link the object.

// geometry.cpp
extern "C" int rectangle_area(int w, int h) { return w * h; }
// demo.ts
// @link ./geometry.o
declare function rectangle_area(w: int, h: int): int;
console.log(rectangle_area(6, 7));   // 42

Strings across the boundary

Strings marshal too: pass a Lumen string to a C function and copy the returned C string back.

// @link ./shim.o
declare function shout(s: string): string;   // C: const char* shout(const char*)

console.log(shout("hi there"));   // HI THERE

FFI marshals scalars (int, i64, number, bool) and strings. This links local/system libraries, it is not a package manager.

Import from a URL

A package is just a URL. The .ts is fetched over HTTPS and inlined at compile time, no package manager, no install step.

import greet from "https://lumen-lang.org/package/std-contrib/hello/hello.ts";

console.log(greet("world"));   // Hello, world!

A remote module can import its own siblings with relative paths, fetched recursively. The same URL is fetched once per build, and import cycles are reported.

Only https:// is allowed. Remote code runs at build time, so import from sources you trust.

Install

curl -fsSL https://lumen-lang.org/install.sh | sh

Windows: download the .zip from the releases page. Self-contained, no other toolchain required.

Then scaffold a project and run it:

lumen init my-app
cd my-app
lumen compile main.ts && ./main

lumen init writes a starter main.ts plus the ambient declarations and tsconfig.json, so the project is editor- and type-checker-clean from the first keystroke.

For a live edit loop, lumen watch rebuilds and re-runs the program whenever the entry file or any of its local imports changes:

lumen watch main.ts            # rebuild and re-run on change
lumen watch --no-run main.ts   # rebuild only
