Packages

Thirty packages, each one plain Lumen with tests, imported straight from a URL: no package manager, no install step, no lockfile. Those marked FFI link a C library and build on the native target (some also ship a wasm archive for the browser).

Formats 6

Parse and write text formats.

csv CSV parser/stringifier with quoted fields, CRLF, row helpers, and flat arrays. toml Practical TOML parser/stringifier for sections, dotted keys, typed values, and simple arrays. dotenv .env parser for key/value config strings. semver Semantic Versioning parser, comparator, incrementer, and range evaluator. markdown Pure-Lumen Markdown -> HTML renderer (no FFI); render(md). pdf FFI PDF text and metadata via Poppler: layout mode, page ranges, document info.

Data 3

Databases and stores, over the C FFI.

plume FFI Typed data-mapper and migration tool over PostgreSQL, SQLite and MySQL via FFI: explicit field/column mapping, projections, relations, checksummed migrations, transactions. sqlite FFI Typed SQLite access via FFI; open/exec/query int and text over a C shim. pgvector FFI Persistent vector store on PostgreSQL + pgvector via FFI: upsert, cosine search, distance bounds.

Servers 7

HTTP servers, sockets, templates and validation.

rest Router and HTTP server: decorated controllers, a route table checked at startup, JSON replies. openapi OpenAPI 3.0 document generation for rest controllers: @openapi/@schema decorators, cross-referenced against the real Route[]. websocket RFC 6455 websockets: handshake, frames, server and client — a browser connects, exchanges and closes clean. socketio A socket.io server the official browser client connects to: Engine.IO and Socket.IO framing over websocket. sse Server-sent events: one-way push over an HTTP response that never ends, with resumption. press Templates for pages: EJS-style tags, escaped by default. validation Rules written on the fields they govern; faults come back as a list.

AI & agents 3

Model APIs, agents and traces.

ai Typed AI helpers for OpenAI-compatible chat APIs: RAG, conversation memory with context compression, structured output, a live tool-calling agent loop, and an MCP client (HTTP, stdio, SSE). agents Agents, prompts, models, MCP links and sub-agents as database rows — run, evaluated and reconfigured over HTTP without a restart. tracing OpenTelemetry traces for AI runs over OTLP/HTTP: spans, generations, tools, token usage — six backends, Langfuse-compatible.

Tooling 7

Using a package

Import an export straight from the package's URL and build as usual. The source is fetched over HTTPS at compile time and compiled in.

import greet from "https://lumen-lang.org/package/std-contrib/hello/hello.ts";

console.log(greet("world"));   // Hello, world!

lumen-lang.org/package/std-contrib/<name>/<name>.ts redirects to the package's repository, and the raw GitHub URL works too. Each package's page has its API, the decisions inside it and how it is tested; the FFI packages document their local build there.

markdown is fast

The pure-Lumen markdown renderer outpaces the popular Node.js Markdown libraries. Rendering a typical ~3 KB document in a tight loop — renders per second, higher is better:

Rendererrenders / sec
markdown (this package)6,775
markdown-it2,020
marked1,064

About 3.4× faster than markdown-it and 6.4× faster than marked on the same document.
